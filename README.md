# lottery
## 高性能派奖系统

这是一个完全基于 **PostgreSQL** 构建的高性能、高安全性的派奖（抽奖）系统。

### 核心架构

本系统的核心特点是，所有业务逻辑，包括复杂的抽奖、奖池轮换、用户资格判断等，全部通过 PostgreSQL 的函数（PL/pgSQL）实现。这种设计的优势在于：

*   **极致性能**：数据操作和业务逻辑在数据库内部闭环，避免了应用服务器与数据库之间频繁的网络通信开销，实现了极高的处理速度。
*   **高安全性**：业务逻辑与数据存储在同一层，可以利用数据库的事务和安全特性来保证操作的原子性和数据的完整性，减少了外部攻击面。
*   **先进架构**：在特定场景下，这是一个非常先进的设计思路，它将数据库的能力发挥到了极致，无需依赖任何外部中间件。
